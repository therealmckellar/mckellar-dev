The term "Fractional FDE" is showing up everywhere in AI consulting right now. But what does a Fractional Forward Deployed Engineer actually *do* day-to-day? Here's the real picture, based on how I run FDE engagements.

## The Core Problem FDE Solves

Most businesses have tried AI tools. They've demoed chatbots, tested Copilot, maybe even built a proof-of-concept. None of it made it to production. The tools sit idle while the team goes back to spreadsheets and email threads.

The Fractional FDE exists because there's a gap between "AI is interesting" and "AI is running in our business." That gap is integration — connecting AI capabilities to your actual workflows, on your actual systems, with real error handling and audit trails.

## The Three Phases

Every FDE engagement follows the same methodology: **Audit → Evaluate → Deploy**.

### Phase 1: Audit (Week 1-2)

This is deep discovery. Not a surface-level assessment — a real operational audit.

- **Stakeholder interviews** across ops, sales, finance, IT, and frontline staff
- **Workflow mapping** — diagram every key path, exception flow, and manual intervention
- **Stack inventory** — list all SaaS systems, APIs, data locations, and security constraints
- **Pain identification** — find the manual work hiding in the margins: "we add things to spreadsheets because the system can't do X"

The output is a clear picture of where your business runs on autopilot and where it runs on manual labor.

### Phase 2: Evaluate (Week 2-3)

Not everything should be an AI agent. The evaluation phase classifies each workflow step:

- **AI agent** — unstructured data, natural language, pattern recognition, multi-step reasoning
- **Deterministic automation** — rules-based, API-triggered, workflow engine
- **Human judgment with better tooling** — decisions that need context but can be supported by dashboards, alerts, and data

For each AI opportunity, we build an ROI matrix: revenue uplift, cost savings, and risk reduction. This ensures we're building the right things first.

### Phase 3: Deploy (Weeks 3-4+)

This is where FDE separates from consulting. We actually build and ship:

- **Agent design** — inputs, outputs, tools, error handling, escalation paths
- **Implementation** — custom agents built on your existing stack (Salesforce, NetSuite, HubSpot, custom APIs)
- **Shadow mode** — agents observe and suggest while humans stay in control
- **Gradual autonomy** — low-risk flows go live first, high-risk decisions keep humans in loop
- **Handoff** — runbooks, documentation, team training

The result is not a slide deck. It's a working system with measurable outcomes.
